# 🌲 Misi Kriptografi: Escape From The Lost Forest

Game pembelajaran berasaskan gamifikasi untuk menguji kemahiran asas kriptografi melalui beberapa misi dalam suasana pengembaraan di hutan.

## 🎮 Tentang Game

Pemain perlu menyelesaikan **5 misi kriptografi** untuk mendapatkan 5 digit kod rahsia. Setelah semua misi selesai, pemain perlu memasukkan kod tersebut ke dalam peti keselamatan untuk membuka laluan keluar dari hutan.

## 🧩 Misi

### Misi 1 — Konsep Kriptografi
Aktiviti padanan istilah berkaitan kriptografi.

### Misi 2 — Caesar Cipher
Menyahkod mesej menggunakan kaedah Caesar Cipher.

**Kod misi:** `3`

### Misi 3 — Rail Fence Cipher
Menyahkod mesej menggunakan Rail Fence Cipher.

**Jawapan:** `MENUJU KE HUTAN`  
**Kod misi:** `5`

### Misi 4 — Substitution Cipher
Menyahkod ciphertext menggunakan jadual penukaran huruf.

**Ciphertext:** `UQJQJ`  
**Jawapan:** `POKOK`  
**Kod misi:** `1`

### Misi 5 — QR Code Rahsia
Imbas QR Code dan nyahsulit ciphertext menggunakan Caesar Cipher Shift -3.

**Ciphertext:** `LNXW NDQDQ`  
**Jawapan:** `IKUT KANAN`  
**Kod misi:** `9`

## 🔐 Kod Akhir

Kod 5 digit perlu disusun mengikut turutan misi:

**`83519`**
